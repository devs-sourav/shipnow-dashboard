# 📖 Project Overview

ShipNow Logistics Dashboard is a modern logistics management dashboard developed as part of the **Frontend Developer Internship Assignment** for **Trends Bird Limited**.

The application closely follows the provided Figma design while maintaining clean architecture, reusable components, responsive layouts, accessibility best practices, and modern frontend development standards.

No backend or external API has been used. All data is managed using local mock datasets.

# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/yourusername/shipnow-dashboard.git
```

Move into project directory

```bash
cd shipnow-dashboard
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```

---

# 📦 Production Build

```bash
npm run build
```

Start production

```bash
npm start
```
